# TziToxicPVP

A responsive, static landing page for the TziToxicPVP Minecraft PvP server. It is ready to publish with GitHub Pages: in the repository settings, choose **Pages**, select the branch and root folder, and save.

## Before launch

- Confirm that the server address and Fabric version displayed in `index.html` are correct.
- The login and signup dialog is a **UI preview only**. GitHub Pages serves static files and cannot securely create accounts or verify passwords. The preview accepts a valid Minecraft-style username, does not check or save the password, and only keeps the displayed player name in the current browser tab's session storage. Do not use real credentials on this demo.
- For real accounts, connect the site to a trusted authentication provider or a server-side authentication API over HTTPS. Never put private API keys or password verification logic in the static site.

## Local preview

Open `index.html` in a browser, or serve this folder with any static web server.
